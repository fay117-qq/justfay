我的专属学士帽

DIY Graduation Cap · Xiaohongshu

图文笔记 · #毕业帽 #seventeen

策划思路

  1. 毕业 + 追星双流量密码：毕业生个性化毕业道具需求 + 粉丝追星应援需求，双重受众叠加；
  2. 内容可复制 + 有情绪：DIY 教程门槛低，且有偶像元素的毕业照戳中粉丝「毕业 + 偶像陪伴」的情感共鸣；
  3. 自带高颜值晒单属性：学士帽装饰色彩明亮、元素丰富（照片、毛球、花朵）。

执行动作

  1. 内容形式：图文 + 标签精准引流（#毕业帽 #seventeen 徐明浩等）；
  2. 细节设计：学士帽上的偶像照片、应援元素，强化粉丝认同感。

结果

1.2万浏览
1801赞藏
95评论
15%赞藏 / 浏览

互动率高于同类图文，且同时触达毕业群体与粉丝群体，实现跨圈层传播。

狙击外星人 关卡攻略

Alien Sniper · Level Guide

攻略合集 · 按关卡编号

策划思路

  1. 强需求内容：《狙击外星人》是轻量化休闲游戏，玩家卡在关卡时会主动搜索攻略；
  2. 内容直观 + 实用：以关卡截图 + 通关思路（圈出目标位置）呈现；
  3. 标题 + 标签精准：标题带关卡数，方便精准搜索，匹配玩家「搜特定关卡攻略」的行为。

执行动作

  1. 内容设计：每关截图圈出「狙击目标」，标题明确关卡数；
  2. 标签布局：带游戏名 / 关卡相关标签，提升搜索曝光。

结果

  1. 单篇最高 5906 浏览，互动量随关卡难度提升而增加，内容实用度高。
  2. 该账号因平台规则调整已停止运营。
